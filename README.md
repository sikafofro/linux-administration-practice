# Linux Administration Practice Toolkit

A hands-on Linux administration portfolio documenting practical exercises in filesystem management, permissions, users and groups, Bash scripting, monitoring, automation, and troubleshooting.

This project supports my development toward **AWS Cloud Engineer and Cloud Support Engineer** roles.

## Project Objectives

- Practise Linux command-line administration.
- Manage files, directories, permissions, users, and groups.
- Write Bash scripts for routine administrative tasks.
- Explore system, disk, service, process, and log monitoring.
- Practise scheduling and basic network diagnostics.
- Document commands, verification steps, and lessons learned.

## How to Use This Repository

1. Browse the `labs/` directory to read the exercises.
2. Review scripts in `scripts/` before running them.
3. Read each script's documentation and check its requirements.
4. Run commands in a suitable Linux environment and verify the results.

**Safety:** Review scripts before executing them. Use test files and directories for practice, and understand any command that changes files, permissions, services, or system configuration.
